# EduPortal Dashboard

A modern, responsive student dashboard for managing academic life, built with HTML, CSS, and JavaScript.

## Project Overview
EduPortal is a single-page dashboard web app designed for students to track assignments, grades, messages, and personalize their learning experience. The interface is clean, mobile-friendly, and features a collapsible sidebar for easy navigation.

## Features

### 1. Sidebar Navigation
- **Dashboard**: Quick academic overview and stats.
- **Assignments**: List of upcoming and pending assignments with due dates and completion stats.
- **Grades**: View current grades by subject and GPA trends.
- **Messages**: Notifications and messages from teachers and administration.
- **Settings**: Customize appearance, notifications, and profile.
- **Collapsible Sidebar**: Save space and show tooltips when collapsed.

### 2. Dashboard Overview
- Academic stats: Pending assignments, average grade, completed projects, new messages.
- Quick actions for fast navigation.

### 3. Assignments
- List of assignments with due dates and subject details.
- Visual indicators for urgent tasks (e.g., "Due Tomorrow").
- Assignment completion and on-time submission statistics.

### 4. Grades
- Subject-wise grade breakdown with teacher info.
- GPA and grade trend stats.

### 5. Messages
- Recent messages and notifications from teachers and school.
- Unread message count and weekly stats.

### 6. Settings
- Toggle dark/light mode.
- Manage notification preferences (email, grade alerts, reminders).
- Edit profile information.

### 7. Dark Mode
- One-click toggle for dark/light theme.
- Remembers user preference using localStorage.

### 8. Responsive Design
- Fully mobile-friendly layout.
- Sidebar slides in/out on mobile, with overlay for focus.
- Touch-friendly buttons and adaptive content cards.

### 9. Smooth UI/UX
- Animated sidebar transitions.
- Loading animation when switching sections.
- Tooltips for navigation icons in collapsed mode.
- Keyboard accessibility (ESC to close sidebar on mobile).

## How to Use
1. **Open `index.html` in your browser.**
2. **Navigate** using the sidebar to view dashboard, assignments, grades, messages, or settings.
3. **Toggle dark mode** using the button in the header or settings.
4. **Collapse/expand sidebar** for more workspace.
5. **Enjoy a seamless experience** on both desktop and mobile devices.
