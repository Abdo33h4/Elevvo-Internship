# Responsive Contact Form

A modern, responsive Contact Form built with **HTML**, **CSS**, and **JavaScript**. This project is designed to be clean, professional, and fully functional on both desktop and mobile devices.

---

## 🚀 Features

- **Responsive Design:**
  - Looks great on all screen sizes (desktop, tablet, mobile)
  - Mobile-first layout with adaptive spacing and touch-friendly inputs

- **Form Fields:**
  - Full Name (requires first and last name)
  - Email Address (with email format validation)
  - Subject (minimum length validation)
  - Message (minimum length validation)

- **Validation:**
  - All fields are required
  - Real-time validation with instant feedback
  - Email format checked with regex
  - Error messages shown below each field
  - Success state styling for valid fields

- **User Experience:**
  - Smooth transitions and animations
  - Loading spinner on submit button during form submission
  - Success message displayed after successful submission
  - Disabled submit button during loading
  - Accessible and keyboard-friendly

- **Styling:**
  - Clean, professional look with gradient backgrounds
  - Rounded corners, hover effects, and box shadows
  - Centered form with max-width container
  - Consistent spacing and typography

---

## 🛠️ Technologies Used

- **HTML5** for structure
- **CSS3** for styling and responsive design
- **JavaScript (ES6+)** for validation and interactivity

---

## 📂 Project Structure

```
├── index.html      # Main HTML file
├── styles.css      # CSS styles for layout and responsiveness
├── script.js       # JavaScript for validation and UX
└── README.md       # Project documentation
```

---

## ⚡ How to Use

1. **Clone or Download** this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Fill out the form and test the validation and responsive design.

---

## 📝 Customization
- You can easily change colors, fonts, or add more fields by editing the CSS and HTML files.
- To connect the form to a backend, replace the simulated submission logic in `script.js` with your own AJAX/fetch code.
